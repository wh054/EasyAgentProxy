# CLI Context Menu Design

## Goal

Add GUI-managed Explorer context menu entries for terminal-first AI CLI tools:

- "在此处打开 Claude"
- "在此处打开 Codex"

The entries open an interactive terminal in the selected folder or the current folder background, inject the EasyProxy proxy environment, and run the corresponding CLI command.

## User Experience

The main EasyProxy window adds a small entry point in the existing "AI 应用代理生成" area: a button named "CLI 右键菜单...".

Clicking the button opens a separate fixed-size dialog. The dialog contains:

- A proxy URI textbox, prefilled from the main window proxy URI.
- Checkboxes for "Claude Code CLI" and "Codex CLI".
- A status area showing whether each menu item is installed and whether its command is discoverable on `PATH`.
- Buttons for "安装/更新右键菜单", "卸载右键菜单", and "刷新状态".

The dialog should not require administrator permission. It writes only per-user context menu entries under `HKCU\Software\Classes`.

## Behavior

When a menu item is installed, EasyProxy writes launcher scripts under:

```text
%LOCALAPPDATA%\EasyProxy\CliContextMenu
```

Each script:

1. Accepts the target working directory as its first argument.
2. Falls back to `%USERPROFILE%` if the directory argument is missing or invalid.
3. Injects the same proxy environment variables generated by `ProxyEnvironmentProfile`.
4. Opens Windows Terminal with the target directory and runs the selected CLI command.
5. Falls back to PowerShell if `wt.exe` is unavailable.

The generated Explorer commands pass the right-clicked directory to the scripts:

- Folder background: `%V`
- Folder item: `%1`

The menu items are installed for both directory backgrounds and directory items.

## Architecture

Add focused classes instead of expanding `AppProxyGuiForm` with registry and script details:

- `CliToolCatalog`: defines supported CLI tools, display names, command names, menu titles, and script names.
- `CliProxyLauncherScriptGenerator`: writes the per-tool `.cmd` launchers using `ProxyEnvironmentProfile`.
- `ExplorerContextMenuManager`: installs, uninstalls, and reports status for the per-user Explorer menu entries.
- `CliContextMenuDialog`: a WinForms dialog for managing the entries from the GUI.

`AppProxyGuiForm` only opens the dialog and passes the current proxy URI. This keeps the main form close to its current responsibilities.

## Registry Scope

Use per-user registry keys:

```text
HKCU\Software\Classes\Directory\Background\shell\EasyProxy.OpenClaudeHere
HKCU\Software\Classes\Directory\Background\shell\EasyProxy.OpenCodexHere
HKCU\Software\Classes\Directory\shell\EasyProxy.OpenClaudeHere
HKCU\Software\Classes\Directory\shell\EasyProxy.OpenCodexHere
```

Each key stores:

- Default value: visible menu title.
- `Icon`: EasyProxy executable path when available.
- `command` default value: `cmd.exe /d /c ""<script>" "%V|%1""`.

Uninstall removes only these EasyProxy-owned keys.

## Error Handling

Install/update validates the proxy URI through `ProxyEnvironmentProfile.Create`. Unsupported schemes are shown as dialog errors.

If a CLI command is not on `PATH`, installation is still allowed. The status area reports the missing command, because users may install the command later without reinstalling the menu.

If Windows Terminal is missing, the launcher uses PowerShell directly. If PowerShell is unavailable, the command shell will show the failure in the opened console.

## Testing

Manual verification should cover:

- Build succeeds.
- Opening the dialog from the main GUI.
- Installing both menu items.
- Confirming registry keys exist under HKCU.
- Refreshing status shows installed items.
- Uninstalling removes the keys.

Automated tests are not currently present in this WinForms project. The implementation should keep logic in non-UI classes where possible so future tests can cover script and registry command generation.

## Out of Scope

- Adding system-wide HKLM context menu entries.
- Modifying installer behavior.
- Creating shell extension DLLs.
- Managing CLI installation through winget/npm.
- Replacing the existing desktop app proxy script generation flow.
